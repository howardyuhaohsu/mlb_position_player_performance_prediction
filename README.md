# MLB Position Player Acquisition Decision System

## Project Objective

This project develops an analytical framework to support MLB free-agent acquisition decisions for position players. Historical player-season data from 2022–2025 are used to study and predict 2026 season performance, including WAR, wRC+, OAA, and plate appearances (PA). The final goal is to combine predicted player performance with expected contract cost to identify cost-effective free-agent candidates for the 2026 season.
